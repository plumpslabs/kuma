# /kuma:studio

Launch or view Kuma Studio web dashboard.

```bash
npx @plumpslabs/kuma studio
```

Opens `http://localhost:3322` featuring:
- **Gotcha Shield** (status filters & 1-click workaround copy)
- **Domain Sequence Flows**
- **Workspace & Blast Radius Simulator**
- **Health & Efficiency Metrics**
- **Calm Knowledge Graph** (physics toggle)
